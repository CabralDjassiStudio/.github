# Contributing to Cabral Djassi Studio Repositories

Thank you for helping improve a Cabral Djassi Studio project.

This is an organization-wide default. Repository-specific documentation takes
precedence.

## Before contributing

1. Read the repository README, license, security policy, and existing issues.
2. Confirm that external contributions are accepted.
3. Discuss substantial changes before implementation.
4. Never include secrets, credentials, customer data, private assets, or
   confidential information.
5. Keep each change focused.

Public visibility does not necessarily mean a repository accepts external code.

## Workflow

1. Create a branch from the default branch.
2. Use a clear name such as `fix/description`, `feature/description`, or
   `docs/description`.
3. Implement the smallest coherent change.
4. Add or update tests.
5. Update documentation.
6. Run formatting, linting, type checks, tests, and build.
7. Submit a pull request using the template.
8. Respond to review comments professionally.

## Quality requirements

Contributions should:

- follow existing architecture and naming;
- include validation and error handling;
- avoid unrelated refactors;
- preserve security, privacy, accessibility, and performance;
- include no secrets or personal information;
- pass required automated checks.

## Commit guidance

```text
feat: add organization language selector
fix: prevent duplicate submission
docs: clarify security reporting
chore: update repository metadata
```

## Pull requests

Explain:

- what changed;
- why it is needed;
- how it was verified;
- security, migration, compatibility, and operational impact;
- visible interface changes with screenshots or recordings.

## Licensing

Every contribution is subject to the target repository's license and
contribution terms. A separate Contributor License Agreement or written
authorization may be required.

Submitting work does not guarantee acceptance, payment, partnership, or release.

## Security and conduct

Follow [`SECURITY.md`](SECURITY.md) and
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
