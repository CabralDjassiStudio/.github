# Cabral Djassi Studio Licensing Policy

This policy guides license selection. It does not replace the `LICENSE` required
in each repository.

## Core rule

**Licenses are selected per repository.**

The license in the organization `.github` repository does not automatically
apply to every project.

## Default matrix

| Repository type | Default |
|---|---|
| Commercial SaaS products | Private, proprietary, all rights reserved |
| Backends and business logic | Private, proprietary |
| Infrastructure and deployment | Private, proprietary |
| Internal design systems and packages | Private package distribution |
| Public integration SDKs | Apache License 2.0 after review |
| Public examples and simple templates | MIT License after review |
| Selected open-core products | AGPLv3 plus commercial license |
| Logos, names, mascots, videos, visual identity | Separate brand permission |

## Before open-source publication

Review:

- ownership of all code and assets;
- third-party licenses;
- patent implications;
- contributor and relicensing requirements;
- brand separation;
- security and operational details;
- business-model alignment.

## Dual licensing

A selected product may use AGPLv3 for open-source use and a separate commercial
license. Clear copyright ownership and contributor terms are required.

## Brand separation

Software licenses do not automatically grant rights over Cabral Djassi Studio
names, logos, icons, mascots, videos, illustrations, or visual identity.

See [`BRAND_POLICY.md`](BRAND_POLICY.md).

## Approval

No repository may be made public, relicensed, or converted between proprietary
and open-source status without explicit owner approval.

Material commercial, trademark, contributor, or dual-license agreements should
be reviewed by qualified legal counsel.
