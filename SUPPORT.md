# Support

## Product and usage questions

Start with the affected repository's README and documentation. Where public
support is enabled, use the appropriate issue form or discussion.

Include:

- product or repository name;
- expected and actual behavior;
- version and environment;
- minimal reproduction steps;
- sanitized logs.

## Bugs

Use the **Bug report** form and search existing issues first.

## Features

Use the **Feature request** form. Describe the user problem, desired outcome,
affected users, and constraints.

## Documentation

Use the **Documentation improvement** form for unclear, missing, incorrect, or
outdated information.

## Security

Never report vulnerabilities publicly. Follow [`SECURITY.md`](SECURITY.md).

## Commercial, partnership, and licensing requests

Use an official channel available on the
[Cabral Djassi Studio website](https://cabral-djassi-studio.vercel.app/).

## Not suitable for public support

- credentials, tokens, private URLs, or secrets;
- customer, employee, or partner information;
- confidential architecture or business information;
- urgent incidents affecting private deployments;
- legal notices or contract negotiations.
